ESPN Roster Sync

One-click roster pull from your ESPN fantasy baseball league. Runs inside your already-logged-in browser tab, so there's no auth flow to defeat — ESPN sees a normal request from your real session.

📥 ESPN Roster Sync

↑ Drag this red button up to your bookmarks bar

Install

1. Make sure your bookmarks bar is visible in Chrome. If not, press Ctrl+Shift+B.
2. Click and drag the red 📥 ESPN Roster Sync button above onto your bookmarks bar. Release to drop it. You should see it appear there as a new bookmark.
3. If dragging doesn't work in your browser, use the “Manual install” section at the bottom of this page.

Use

1. Open fantasy.espn.com in Chrome and log in if needed.
2. Navigate to your league. Any page where the URL contains leagueId=... will work — the league home, standings, your team, etc.
3. Click the 📥 ESPN Roster Sync bookmark in your bookmarks bar.
4. A file named espn_rosters_{leagueId}_{date}.json will download to your Downloads folder.
5. Send that JSON file back to me — I'll use it as the source schema to write the parser against your actual league data.
First-run note: If the bookmarklet pops up an alert with a 401 or 403, it means your ESPN session has expired in that tab. Refresh the league page (or click any link on it) to reactivate the session, then click the bookmarklet again. This is the same thing that would happen if you just sat on the page idle for an hour.

What it does

The bookmarklet calls ESPN's fantasy API endpoint at lm-api-reads.fantasy.espn.com with three views: mRoster (every team's full roster including players, position eligibility, and IL status), mTeam (team names, owners, abbreviations), and mSettings (league lineup configuration including the position slot definitions). It auto-detects the league ID from your current URL and the season from either the URL or the current calendar year.

The downloaded JSON wraps ESPN's raw response with a fetchedAt ISO timestamp plus the leagueId and seasonId for traceability. Nothing is modified, filtered, or interpreted — it's the raw API payload, which is what I want for Phase 1 so I can write the parser against your league's actual schema instead of guessing at field names.

Manual install (if drag-and-drop doesn't work)

Right-click your bookmarks bar → Add page… → set the Name to 📥 ESPN Roster Sync and paste the entire string below into the URL field:
